# Portfólio

Site pessoal de Welber Caetano Santos. Página única, estática, publicada no GitHub Pages.

**https://welberc1.github.io/CurriculoEmSite/**

## Stack

React 19, TypeScript e Vite. CSS puro com custom properties, sem framework. Fontes auto-hospedadas. Sem backend e sem chamadas de API em runtime.

## Rodando local

```bash
npm install
npm run dev
```

`npm run build` gera o `dist/`. O deploy roda sozinho a cada push na `master`.
